# Creative range and reusable production

2D and 3D describe representations; explainers, title sequences, launches and identities describe uses. Select a representation and a visual argument from the brief. The agent authors the film; shared code handles mechanics. There is no prompt-to-example dispatch table.

## Select the difficult creative problem

| Approach | What needs to work | Useful infrastructure |
|---|---|---|
| Expressive typography | Meaning survives deformation, interruption, line changes and reading holds | Measured glyph layout, arbitrary numeric tracks, masks, shot-local clocks |
| Editorial collage | Independent assets form one argument; cuts preserve a direction, contour or relationship | Source-aware cover crops, scoped masks, parent transforms, decoded image readiness |
| Character performance | Gaze and anticipation establish intention; contact and consequence communicate effort | Named pose tracks, rigid limb lengths, parent transforms, held cels where appropriate |
| Brand and title families | Different pieces share a recognizable behavior while their content and layout vary | Editable content and brand inputs, shared geometry/motion functions, multiple authored compositions |
| Product/UI storytelling | A user action visibly changes the product state and motivates the next shot | Content models, local timing, persistent object identity, measured exact copy |
| Sound-led or generative work | Musical contrast or data relationships produce visible structural changes | Measured envelopes/bands/onsets, arbitrary track sampling, seeded construction data |
| Graphics within footage | Overlay placement follows source motion and disappears or repairs when tracking fails | Exact media seeking, feature tracking, homography mapping, authored occlusion masks |

The table is a decision aid, not a required scene structure. A still hold, abrupt cut, wordless scene, monochrome frame or long developing shot can be appropriate. Do not force every film into a hero reveal, headline, card grid and closing slogan.

## Preserve freedom at the authoring boundary

Keep sample words, palettes, model geometry, character proportions and shot beats in the example project. General helpers should take numbers, text, paths, images, poses, audio features, or tracking samples. A helper that switches on a sample ID or a few prompt keywords to select a completed scene is not general infrastructure.

Concrete scene code necessarily records specific design decisions. Make the intended content and controls editable, but do not pretend that substituting a noun automatically redesigns a film. If the new brief changes the meaning or relationship, author a new composition using the same mechanics. Do not increase a component's API merely to imitate a speculative future project.

Preserve three separate things:

1. The exact user-level prompt before elaboration.
2. The chosen creative contract, assets, shot plan and meaningful repairs.
3. The editable source, dependency versions, local assets and export settings.

An exact project replay fixes the latter two. Repeating the first alone invites a fresh interpretation and may require different assets. Hashes and repeated-seek checks establish source/frame integrity on the measured runtime; they do not guarantee bit-identical encodes across different browsers, operating systems, fonts or codecs.

## Build the right proof

Prove the uncertain relationship before a full export. For character work, inspect the target contact and the extreme expression; for type, use actual longest copy and the reveal boundary; for collage, inspect the independent asset crops; for UI, verify the represented state change; for tracking, inspect the fitted surface and its lost intervals.

Use fresh briefs to assess broader authoring. A content-only variation proves control editability. A synthetic moving plane proves tracking geometry under known conditions. Neither alone proves arbitrary prompt quality or robust live-action integration. Preserve which claim each check actually supports.

## Authored examples

The [creative-range index](../examples/index.json) records five independent briefs with portable projects. They include distinct typographic, photographic, puppet, product/identity and audio-driven approaches. Their copy, colors, durations and story beats are local creative choices, not skill-wide defaults. Their successful renders are inspected demonstrations, not a measured first-attempt quality benchmark.

Reference research informed the breadth of approaches: [Google Sans Flex](https://studiodumbar.com/work/google-sans-flex), [BUCK Australian Open](https://buck.co/work/australian-open), [Oswell](https://buck.co/work/oscar-ai-agent), [Playgrounds](https://buck.co/work/playgrounds-in-motion), and [Ordinary Folk Webflow](https://www.ordinaryfolk.co/project/webflow-a-new-era-of-no-code). No source artwork or studio animation code is bundled from these case studies.
